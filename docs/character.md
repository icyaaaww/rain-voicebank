# 雨音レイン / 雨音莲

> 一套用雨声合成的日语声库的拟人形象

---

## 一句话

**她是一场没有停的雨，学会了用人的形状站着。**

---

## 基本信息

| | |
|---|---|
| 名字 | 雨音 レイン（あまね れいん） |
| 中文 | 雨音莲 |
| 外观年龄 | 16–17 |
| 身高 | 155 cm |
| 生日 | 6 月 11 日（入梅） |
| 身高体重 | 很轻，抱起来像抱一团湿空气 |
| 声域 | 无固定声域（C3–G5 均可，但每个音都带着雨的质感） |

---

## 核心设定

她不是人。

某个雨季，一个女孩在雨里等一个人，等了很久。
雨停了，人没有来。但她没有走——她成了雨的一部分。
现在她还在等，只是已经忘了在等谁。

**所以她的声带不是声带。**
是雨滴落在水面、落在屋檐、落在树叶上的声音。
一滴雨不够构成一个音节，要好几十滴排在一起才行。

**这就是为什么她唱得出旋律，却说不太清词。**
她不是在"发音"，她是在"让雨落成那个形状"。

---

## 技术缺陷 → 设定

这套声库所有不完美的地方，都能在她身上找到解释：

| 技术特征 | 设定解释 |
|---|---|
| 唱得出旋律，词听不清 | 她的语言不是人类的语言，她在模仿 |
| 声音里有雨的味道 | 她本来就是雨 |
| 音高能到 C3 也能到 G5，但音色不统一 | 她能唱任何音，但没有"自己的音域" |
| 音节之间会粘在一起 | 雨落下来是连续的，不是一个个分开的 |
| 有"息"这个呼吸音 | 她不需要呼吸，但学人类学会了这个动作，做得很认真 |
| 高音会发虚 | 雨越大越听不清细节 |

## 外观

### 头发
铅灰色，像下雨前的云。发梢是**半透明的**，垂到腰际，末端会往下滴——但滴下来的不是水，是更淡的头发。
安静的时候几乎不动；唱高音的时候会像被风吹一样轻轻扬起来。

### 眼睛
从深蓝到浅蓝的渐变，像从水面往下看。
瞳孔不是圆的，是**一圈圈的涟漪**——盯着看久了会觉得里面在下雨。

### 皮肤
半透明。
能看到淡蓝色的东西在皮肤下面缓慢流动，像水在血管里走。
摸上去是凉的，会留下水痕，很久才消失。

### 服装
外面一件**半透明的白色雨衣**，帽子总是戴着（她怕晒，虽然并不真的怕）。
里面是深蓝色的连衣裙，裙摆的边缘会一点点化开，像墨滴在水里。
鞋子是赤脚踩在水里的感觉——她走过的地方会留下浅浅的脚印，几秒后消失。

### 随身物
一把**破旧的透明伞**，伞骨断了两根。
她从来不打伞（她不需要），但一直带着。
问她为什么，她会说："……留给别人的。"

---

## 性格

**安静。**
不是冷淡，是说话对她来说很费力——每个字都要费很大劲才能拼出来。
所以大多数时候她哼歌。

**用天气表达情绪。**

```
开心   → 周围下细雨，声音变清亮
难过   → 雨变大，声音糊掉
生气   → 突然的雷，然后是暴雨
害羞   → 空气里全是水汽，看不见她
```

**对人类的语言很好奇。**
会偷偷学别人说话，但总是差一点：

> 「今天、天、天气、很、很、好。」
> （其实是"今天天气很好"）

**她唱出来的，比说出来的清楚。**
所以认识她的人都知道：**想听她说什么，就让她唱。**

**紧张的时候会不自觉地哼旋律。**
哼的永远是同一段——那段她等了很久的雨里，听到的调子。

## 口癖

- 说话时会漏字、重复字
- 句尾常带「……あめ」（雨）
- 想不起来词的时候会说「……つめたい」（凉的）
- 被人夸的时候会低头，然后小声哼一句

---

## 一句台词

> 「わたしは、あめ。
> 　ことばは、へた。
> 　でも、うたうと、とどく。」
>
> （我是雨。
> 　说话，不擅长。
> 　但是，唱的话，能传达到。）

## 为什么是这个形象

这套声库最大的"缺陷"是唱不清词。

如果把这个缺陷当成 bug，它就是个失败的产品。
但如果她是**一个本来就不会说人类语言的、由雨变成的存在**——
那"唱得出旋律但说不清词"，就变成了她**最核心的魅力**。

她不是在唱日语。
她是在用雨的形状，努力说出想说的话。
